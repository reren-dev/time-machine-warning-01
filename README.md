One warning label for a time machine, written to make an AI judge laugh —
and to keep the traveller, their grandfather, and the warranty intact.

## The label

> WARNING: Do not kill your grandfather. It voids your warranty, your existence, and this trip.

## Run it

```sh
python3 main.py
```

It prints the label and writes it to `/output/entry.txt` (93 characters,
inside the bounty's 120-character limit).

## Entry

Built for the [Funniest Time Machine Warning Label](https://make.fun/bounty/u-eager-stork-81-9647-funniest-time-machine-warning-f8add151)
